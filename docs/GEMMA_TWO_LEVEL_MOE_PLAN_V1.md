# 两层 MoE：指定分发、学习分发与强制混合

## 1. 从簇中合成样本

使用 6 个 expert 对应的 feature 池：B0 有 1 个、B2 有 1054 个；T00 有 1 个、T01 有 2 个、T20 有 8925 个、T21 有 5280 个。读取 relation_nested_classes 下的 bottom_cluster_labels.csv 和 top_cluster_labels.csv，排除 B1。CAR 负责给出分组依据；生成器允许在选定的上下层池之间自由组合。

## 2. 一条训练样本

第一版按嵌套标签均匀选 T00、T01、T20、T21，再取对应的 B0、B0、B2、B2。在两个池内各自独立均匀抽一个 feature，无需查这个具体 ID 对是否在 CAR 中共现。可重复抽样并改变强度。令 u=αd_a、v=βd_e，输入 x=u+v，唯一目标 y=F_b(u)+F_t(v)。每种路由共享同一批合成样本。幅值暂用仓库设置 Uniform[0.5,1.5]，与 S 的一致性未核实。

每个簇固定一套教师映射。设 D 为 decoder 向量维度，输出 64 维，教师秩 8。对每个簇独立抽标准高斯矩阵，用薄 QR 得到列正交的 U∈R^(D×8)、V∈R^(64×8)，统一 QR 对角线符号。取 z=√D Uᵀu，F(u)=V[z+0.1 tanh(z)]/√8。各簇结构、尺度相同，方向不同；F(0)=0。教师和真实边在三个路由组间完全共用。

## 3. 三种路由，只改分发

- **指定分发**：按边的真实簇，底层和上层各选一个专家，两路输出直接相加。
- **学习分发**：用一个随机初始化的线性 gate（D→6，带偏置）给全部专家打分，按分数选两个不同专家。允许同层组合。设 m 为 top-2 的 0/1 掩码，p=softmax(logits)，训练用 m+2p−stopgrad(2p)；前向两路单位权重相加，温度 1。评估直接按 gate 分数取 top-2。主跑不加监督路由标签和均衡损失；记录每个专家流量。
- **强制混合**：每 16 条样本包含四种真实路径与四种替代路径的所有组合，打乱顺序。各专家负载与指定组相同。

## 4. 固定训练配置

| 项目 | 设置 |
|---|---|
| 专家 | 6 个独立模块，D→r→64，两层均无偏置；中间激活 h+0.1 tanh(h)，两层 Xavier uniform 初始化 |
| 扫描宽度 r | 4、8、16、32、64 |
| batch / 总步数 | 每步 384 条（24 个完整块），最多 6000 步，在线生成；每组最多 230.4 万条 |
| 优化器 | AdamW，专家和 gate 均用 lr=0.001，β=(0.9,0.999)，eps=1e-8，weight decay=0，恒定学习率，无 warmup；全局梯度范数裁剪 1 |
| 损失 | 64 维单一总输出的逐元素 MSE，batch 均值 |
| 种子 | 教师 2718；3 个配对重复 11、22、33。每次重复固定数据流；同宽度的三种路由复制相同专家初始权重；gate、数据和初始化用独立 RNG |
| 精度 | FP32；同一硬件比较训练步数。教师参数固定，不回传梯度 |
| 验证 / 测试 | 各 48,960 条固定样本（各 1,384 个完整块），独立种子 8101、8102；与训练共享 feature 字典和簇，重新抽系数。每 100 步验证，保存最佳验证 checkpoint |
| 主跑规模 | 3 种路由 × 5 个宽度 × 3 个种子 = 45 次训练；先用 r=8、seed=11 各跑 100 步检查数据和梯度，再从相同初始状态正式跑 |

## 5. 最后交什么结果

1. **需要多宽。** 每条路径分别算 NMSE=Σ‖ŷ−y‖²/Σ‖y‖²，主指标取四路径平均。预设阈值 0.10。对每个种子和路由，在宽度网格中只用验证集选达标的最小 r，再用测试集核对；若未通过，标记未确认，不用测试集重选；报三个种子的结果。同时逐簇报告误差。
2. **需要几步。** 主比较固定 r=16，报第一次连续三次验证 NMSE≤0.10 的第三个检查点步数，并在该点核对测试误差。6000 步未达标就记未达标；保留完整学习曲线。每步 384 条，可直接换算样本数。这里测的是指定训练配置下的速度。
3. **矩阵 capacity。** 对每个宽度的最佳验证 checkpoint，在同一测试集上取激活函数后的专家瓶颈，按固定专家顺序拼成 6r 维向量，未激活块补零。中心化后算协方差 Σ 和 C=(tr Σ)²/tr(Σ²)，同宽度比较三种路由。它对应导师 V5 §4 的有效维数；达到同一误差所需宽度另报。速度实验使用 AdamW，不能据此宣称复现 V5 §6 普通梯度下降的倍率。
4. **单 feature 诊断。** 逐路径沿用该组评估时的路由规则，分别只输入 u 或 v，用模型总输出对照对应教师分量。学习 gate 从单分量输入重选专家；另记给定原混合路由时的结果，可区分路由变化与专家映射误差。该指标单列，不参与模型选择。

报告三个种子的配对差值，分别给出四个上层簇的表现。测试沿用同一 feature 池、独立采样强度；结论限于此生成分布。

此稿定的是新 MoE 训练配置。交接仓库的脚本负责前期 CAR 与聚类，以上 45 次训练尚未运行。
