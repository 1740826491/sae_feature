# 已知层级分发能否用较低秩学好叶映射？

**结论：混合验证 NMSE 要求为 0.023 时，三个种子的指定 MoE 都在 1200 步达标。全宽 Dense 两次达标，用了 1700 和 2100 步；折算累计前向矩阵乘加量，分别是 MoE 的 4.23 倍和 5.23 倍。第三次 Dense 跑到 6000 步仍未达标。这是回看精度曲线得到的预算比；没有测到统一的五六倍墙钟加速。**

## 长尾结果：单独输入叶分量时学得怎样

取第 6000 步模型，把底层输入置零，仅输入叶向量 v。用模型总输出预测已知的叶目标，报告 $L_{\rm leaf}=\sum_n\|\hat y(v_n)-y_{\rm leaf,n}\|_2^2/\sum_n\|y_{\rm leaf,n}\|_2^2$。每组测 49152 条样本，三个种子等权平均。

|模型|叶 NMSE|底层 NMSE|混合 NMSE|
|---|---:|---:|---:|
|指定分发|0.00313|0.00097|0.00203|
|强制混合|0.03958|0.00885|0.02407|
|学习 top-2|0.10551|0.03209|0.06744|
|全宽 Dense|0.03885|0.00801|0.02327|

同容量、同负载的混合组叶误差约为指定组的 12.6 倍。这里测的是末步叶分量恢复；文中 0.023 达标步数使用混合验证 NMSE。

## 分别以 common、leaf 或混合输出为目标，倍率是多少？

统一采用验证 NMSE ≤ 0.023，连续三次达标，每 100 步评估一次。种子依次为 11、22、33。每步 Dense 与指定 MoE 的前向矩阵乘加量之比是 12,845,056 / 4,300,800 = 2.9867。因此两者都达标时，计算预算比等于 2.9867 × Dense 步数 / MoE 步数。

|达标对象|Dense 步数|指定 MoE 步数|Dense 相对指定 MoE 的累计前向矩阵乘加量|
|---|---|---|---|
|底层 common|400 / 400 / 400|800 / 800 / 800|三次均为 1.49 倍；Dense 只用了 MoE 一半的样本|
|长尾 leaf|三次均未达，预算各 6000 步|1500 / 1500 / 1500|Dense 已消耗 11.95 倍的预算，仍未达标；实际达标成本比未知|

按相同的 6000 步训练预算比较末步测试误差，则 Dense/指定的 common NMSE 比为 8.28，leaf NMSE 比为 12.41；强制混合/指定的对应比值为 9.15、12.65。误差倍率按三个种子的未舍入均值相除，与上表的计算倍率含义不同。

## 昨天的问题，今天能回答到哪里

导师 V5 §5 关心分开存储会怎样改变细节特征受到的干扰。我们把这个问题落到三个可测判断：① 有限秩下，同一批数据按真实路径分发是否降低叶误差？② 只给叶分量时，模型能否恢复对应的映射？③ 随着秩放开，两组差距是否消失？前两个用同容量的指定与强制混合 MoE 比；第三个用此前的秩曲线回答。最后再用方阵 Dense 核算达到共同精度所需的样本和矩阵计算。这轮训练采用 AdamW，不能据此复现 V5 §6 普通梯度下降下的理论学习率倍率。

## 任务：从混合输入预测两个处理结果的和

这是一个监督回归任务。生成器掌握两个干净分量，学生只看它们的和。我们希望检验：当不同样本共享部分处理规则时，让这些样本复用同一个专家，能否更准确地学到其中的叶规则？

### 第一步：一条样本的两个 feature 从哪里来？

输入方向取自 Gemma 2 9B 第 27 层 residual SAE 的 decoder。先导实验用 CAR 统计区分底层 constituent 和上层 composite。本轮从 B2、T20、T21 三个已有 feature 池出发，每个池按 decoder 方向分成两个簇。每簇对应一个专家和一套固定教师规则，共六簇。生成器按同编号配对，构造下表四条路径。这一步定义了合成树；槽内任意一对都可以抽到，无需它们曾在真实文本中同时激活。

|路径|底层池（可抽方向数）|叶池（可抽方向数）|每批样本数|
|---|---|---|---:|
|1|B2₀（760）|T20₀（2687）|96|
|2|B2₁（294）|T20₁（6238）|96|
|3|B2₀（760）|T21₀（2816）|96|
|4|B2₁（294）|T21₁（2464）|96|

路径 1 和 3 共享同一套底层规则，各自使用不同的叶规则。因而每个底层规则出现在一半样本里，每个叶规则出现在四分之一样本里。文中 common 指这个被复用的底层分量，leaf 指路径特有的上层分量。

### 第二步：用一条真实导出记录算 x 和 y

样例文件第一行抽到了路径 1。底层 feature ID 是 48908，叶 ID 是 51646。它们各自的单位 decoder 向量记为 dₐ 和 dₑ，每个有 3584 个坐标。生成器从 [0.5, 1.5] 独立均匀抽两个系数，这一行分别为 0.88119 和 1.15007。于是：

- 底层贡献 u = 0.88119 dₐ，叶贡献 v = 1.15007 dₑ。
- 学生看到的输入 x = u + v，是一个 3584 维向量。
- 教师给出的唯一答案是 y = T底₀(u) + T叶₂₀₀(v)，同样有 3584 个坐标。这里 T叶₂₀₀ 表示 T20 的第 0 簇的教师规则。

**生成公式（与代码一致，向量均写成行向量）。** 设 $a$ 属于底层簇 $b$，$e$ 属于叶簇 $t$，$d_a,d_e$ 是单位 decoder 方向。每条样本独立采样两个幅值：

$$
\alpha,\beta\overset{\mathrm{iid}}{\sim}\mathrm{Uniform}(0.5,1.5),\qquad
u=\alpha d_a,\quad v=\beta d_e,\quad x=u+v.
$$

定义共享矩阵 $A=PWH$ 和每个簇的修正矩阵 $B_g=P\Delta_g H$。则教师答案可以写成一行：

$$
\boxed{y=\underbrace{xA}_{\text{各簇共用}}
+0.25\underbrace{(uB_b+vB_t)}_{\text{按两个来源簇分别计算的修正}}.}
$$

等价地，单个簇的规则是 $T_g(w)=w(A+0.25B_g)$，因此 $y_{\rm common}=T_b(u)$、$y_{\rm leaf}=T_t(v)$、$y=y_{\rm common}+y_{\rm leaf}$。文件字段 common 指底层分量的完整教师输出，其中也包含该底层簇自己的修正。0.5 是采样幅值的下界；0.25 是固定的簇修正系数。

**矩阵怎样复现。** $P$ 是 $3584\times597$ 的随机投影，正交列乘 $\sqrt{3584/597}$；$W$ 是 $597\times597$ 的固定正交矩阵；$H$ 是 $597\times3584$ 的保距扩维矩阵，满足 $HH^\top=I$。令 $Z_g$ 的每行是簇 $g$ 的一个单位方向乘 $P$，分别生成两个 $597\times8$ 的列正交矩阵 $U_g,V_g$，按代码定义：

$$
R_g=U_gV_g^\top,\qquad
\Delta_g=\frac{\lVert Z_gW\rVert_F}{\lVert Z_gR_g\rVert_F}R_g.
$$

因此在整个簇的方向集合上，修正项的范数恰好是公共项的四分之一。单个样本的比例会变化。所有教师矩阵在训练开始前固定。

把例子里的底层 ID 换成本簇另一个 ID，T底₀ 保持不变，答案随新的 u 改变。若从路径 1 换到路径 3，则保留 T底₀，改用 T21 第 0 簇的叶规则。这样分发标签只能告诉专家“哪套规则适用”，没有透露输入方向、幅值和最终答案。

### 第三步：四个学生怎样答同一道题？

|模型|对同一 x 如何预测 ŷ|
|---|---|
|指定分发|路径 1 直接激活 B2₀、T20₀ 两个专家。每个都读完整的 x，输出相加。|
|学习 top-2|一个随机初始化的线性 gate 只看 x，从六个专家中任选两个。专家和 gate 一起学习。|
|强制混合|每 16 条样本包含四条真实路径与四条替代路径的全部组合，打乱顺序。每个专家与指定组收到同等数量的样本，但样本的处理规则被混在一起。|
|Dense|对所有路径使用同一张可训练的 3584×3584 矩阵，预测 ŷ=Mx。|

一个专家的有效矩阵 Mᵢ 由两层无偏置线性变换 3584→300→3584 相乘得到，中间没有激活函数。每条样本的 MoE 预测为 **ŷ=Mᵢx+Mⱼx**。教师计算的是 T底(u)+T叶(v)，学生训练时分解不开现成的 u、v；两个学生专家都需要从混合向量工作。只有指定组额外知道真实专家对。

### 第四步：训练 loss、达标指标、叶误差分别怎么算？

**训练 loss。** 每个 batch 有 B=384 条样本，输出维度 D=3584。优化器最小化 **L = Σₙ‖ŷₙ−yₙ‖²/(B×D)**，即对每条样本的每个输出坐标取平均平方误差。只有总输出的一项监督。AdamW 学习率 0.001、权重衰减 0，每组跑 6000 步。每步重新采样，所以每个模型见到 230.4 万条样本曝光；三个种子 11、22、33 各自生成数据流，同一种子下各模型复用同一数据流。

**达标指标。** 验证曲线记录混合 NMSE = Σₙ‖ŷₙ−yₙ‖² / Σₙ‖yₙ‖²。例：0.023 表示预测残差平方和为目标能量的 2.3%。每 100 步用同一批 3072 条验证样本检查；连续三次都 ≤0.023，以第三次的步数确认达标。训练优化的是上面的 MSE，文中所有达标倍数均按验证 NMSE 算。0.023 是回看曲线选择的报告阈值。

**末步分量测试。** 固定第 6000 步模型，另生成 49152 条测试样本。对同一组抽样测三次：① 输入 u+v，对照总答案 y；② 输入 u，对照 T底(u)；③ 输入 v，对照 T叶(v)。每次按对应目标自己的能量归一化。因此 common 与 leaf 两列不能直接相加得到混合 NMSE。指定组和强制混合组沿用原专家对；学习组用单分量重新选路。叶误差回答“单独给叶信号时能恢复多少”，不等于从混合预测中唯一分解出某个学生专家的贡献。

## 学到了什么

三个种子的末步平均测试 NMSE（越小越好）：

|模型|混合|底层单独输入|叶单独输入|
|---|---:|---:|---:|
|指定分发|0.00203|0.00097|0.00313|
|强制混合|0.02407|0.00885|0.03958|
|学习 top-2|0.06744|0.03209|0.10551|
|全矩阵 Dense|0.02327|0.00801|0.03885|

同样六个专家、同样激活两个，强制混合的叶误差是指定分发的 12.6 倍。全矩阵 Dense 的叶误差是指定分发的 12.4 倍。该倍率描述最终误差，单分量评估使用训练时未单独输入的叶向量。

## 参数、样本和计算分别算账

全矩阵 Dense 有 3584² = 12,845,056 个权重。单个秩 300 专家有 2×3584×300 = 2,150,400 个。六个专家合计 12,902,400 个，比 Dense 多 0.45%；指定分发每条样本用两个专家，共 4,300,800 次前向矩阵乘加，约为 Dense 的 33.48%。这组模型的总参数几乎相等，每步实际用到的权重数相差约 2.99 倍。

|混合验证阈值|Dense 确认步数|指定 MoE 确认步数|结论|
|---|---|---|---|
|0.05|500|900|Dense 样本更少；其累计前向矩阵乘加量为 MoE 的 1.66 倍。|
|0.025|1000|1200|Dense 样本更少；其累计前向矩阵乘加量为 MoE 的 2.49 倍。|
|0.023|1700 / 未达 / 2100|1200 / 1200 / 1200|MoE 均用 46.08 万条；两个共同达标种子中，Dense 用 1.42、1.75 倍的样本，4.23、5.23 倍的前向矩阵乘加量。另一个 Dense 看完 230.4 万条仍未达。|

每 100 步验证，连续三次达标才确认。上表阈值由回看曲线得到；不把未达标种子折算为有限加速。计算量按前向矩阵乘加数估算，未计反向、优化器、数据生成或墙钟开销。

## 与前几轮的关系

早先的 597 维输出实验用秩曲线检查了容量瓶颈：秩 100 时，混合与指定的叶误差绝对差为 0.0825，秩 300 时为 0.0392，秩 597 时仍为 0.0396。紧瓶颈加重了混合的代价，放开秩后收益仍然存在。此前非线性实验还发现协方差有效维数更高并不保证叶预测更准。不同实验的输出矩阵形状不同，计算倍率分别核算。

## 可以对外说的结论

在这套可控任务里，真实路径已知时，低秩专家能够更准确地学习叶映射。方阵任务中，总参数近乎匹配，指定 MoE 获得约 12.6 倍的叶误差改善（相对混合）；在两个模型均达到 0.025 的三个种子上，累计前向矩阵乘加量约节省 2.49 倍（相对 Dense）。精度要求改变，样本优势和计算倍率也改变。实验尚不能给出真实语言模型的墙钟加速或跨 K 的 scaling law。
