# 方阵实验数据说明

每批 384 条，四个路径槽各 96 条。每次训练 6000 批，共 2,304,000 次样本曝光。三个种子有三条训练数据流；同种子下四种模型复用同一条数据流。每次最终测试使用 49,152 条混合样本，并对相同抽样分别测试单独底层和单独叶分量。导出的 analysis_sample.npz 是测试集的首批 384 条。

|路径槽|底层池大小|叶池大小|
|---|---:|---:|
|B2 簇0 + T20 簇0|760|2687|
|B2 簇1 + T20 簇1|294|6238|
|B2 簇0 + T21 簇0|760|2816|
|B2 簇1 + T21 簇1|294|2464|

槽内独立均匀选两个 ID，四槽合计 6,740,668 种离散配对。取各自单位 decoder 方向并乘独立 Uniform[0.5,1.5] 强度，得到 u、v，输入 x=u+v。固定教师先将两个分量投影至 597 维，分别施加公共映射及强度为 0.25 的簇专属低秩修正，再以共享的保距线性变换扩到 3584 维。两个贡献相加得到唯一监督 y。训练流由种子在线重建，离散配对可重复。

本目录 analysis_sample.npz 提供 feature_ids、expert_ids、strength（各 384×2，先底后叶），以及 x、y、y_common、y_leaf（各 384×3584）；y≈y_common+y_leaf。results.jsonl 保存 12 组末步测试结果和阈值步数。生成入口在仓库 scripts/run_linear_rank.py 的 Task.batch 和 --square-output 分支。服务器目录 /mnt/workspace/Hrj/gemma_hierarchy/square_1124/ 保存实际执行的代码、曲线与检查点。
