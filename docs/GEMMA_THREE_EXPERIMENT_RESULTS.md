# Gemma SAE 合成映射实验：三轮结果

**结论。** 固定完整输入、相同样本和 6000 步，已知路径的低秩线性 MoE 显著降低了叶映射误差；给 gate 自己学习、换成非线性任务或改变比较预算，排序都可能改变。

每条样本混合一个底层与一个叶 feature。K 个底层组配 2K 个叶组，每条路径等概率；每个叶组曝光量是其底层组的一半。训练只监督两个教师分量之和。Common 和叶列分别是单独输入对应分量后的总输出测试 NMSE，越低越好。学习 gate 在单分量测试中重新选路。所有正式比较均使用 batch 384、6000 步（230.4 万次曝光）。表内为三个配对种子的均值，公共线性校准例外。

## 讨论边界

指定组知道生成路径。线性六专家秩 300 共 7,525,800 个参数，每条样本用两个专家；全宽线性 Dense 共 2,139,648 个参数。相同步数等于相同曝光量，但不等于相同参数或 FLOPs。数据划分检验同一 feature 池、同一组规则下的新采样实例。三个种子共用每个 K 的教师，未检验跨教师稳定性。K=2 和 4 只构成两点趋势，且教师随 K 改变。
